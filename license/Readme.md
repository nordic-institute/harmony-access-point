The folder contains licenses for third-party software used in this project.
The license filename are using the id from the [SPDX License List](https://spdx.org/licenses/ file,
and are manually downloaded from the respective website.

List matches the respective list generated file:
[THIRD-PARTY.txt](../../target/generated-sources/license/THIRD-PARTY.txt) file.
The file is generated by the *license-maven-plugin* using the command below.

The plugin downloaded licenses are located in folder
_target/generated-resources/licenses_
after the one of the below maven "Check license commands" is executed.

**STEPS**

**1. Check license commands:**

```shell
 mvn clean process-resources -P weblogic-ecas,database,tomcat,sample-configuration,weblogic,license-generate-notice,wildfly,distribution,default-plugins,licenses-process
```

**2. Copy and commit the generated files:**

After running one of these commands (even if the command fails), the generated [Domibus_main_folder]\target/generated-sources/license/THIRD-PARTY.txt file needs to be copied to [Domibus_main_folder](overwrite the existing file).
Repeat step 1 until the command succeeds.
The [Domibus_main_folder]/THIRD-PARTY.txt and [Domibus_main_folder]/Notice.md files need to be committed to the repository.

**Troubleshooting**:

If the following error is encountered:

[INFO] --- antrun:3.1.0:run (compare-files) @ domibus ---
[INFO] Executing tasks
[WARNING]      [echo] check THIRD-PARTY.txt changes
[WARNING]      [echo] [Domibus_main_folder]/THIRD-PARTY.txt
[WARNING]      [echo] [Domibus_main_folder]\target/generated-sources/license/THIRD-PARTY.txt
[INFO] ------------------------------------------------------------------------
[INFO] Reactor Summary for Domibus MSH 5.1.x-SNAPSHOT:
[INFO]
[INFO] Domibus MSH ........................................ FAILURE [01:50 min]

it means that the generated file [Domibus_main_folder]/target/generated-sources/license/THIRD-PARTY.txt is different from the existing file [Domibus_main_folder]/THIRD-PARTY.txt.
In this case the existing file([Domibus_main_folder]/THIRD-PARTY.txt) needs to be overwritten with the generated one([Domibus_main_folder]/target/generated-sources/license/THIRD-PARTY.txt), and the above command needs to be re-run.
